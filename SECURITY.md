# Политика безопасности

Если вы нашли уязвимость, не открывайте публичный issue.

## Как сообщить

- Используйте GitHub Security Advisories, если они доступны для репозитория.
- Если это невозможно, свяжитесь с мейнтейнером напрямую:
  - Telegram: https://t.me/nekoty

По возможности приложите минимальное воспроизведение и оценку влияния.
