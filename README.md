# MISIS schedule bot

Единый Python-проект для Telegram и VK бота с общим парсером расписания, локальной SQLite базой, админкой и автоматическими уведомлениями об изменениях.

## Что умеет

- парсит расписание с сайта колледжа
- показывает расписание на сегодня, завтра и 2 дня
- автоматически регистрирует пользователей после первого сообщения
- каждый день в `00:00` сохраняет ночной baseline расписания
- каждый час перепроверяет сайт и рассылает уведомления об изменениях
- хранит пользователей, слепки расписания и историю изменений в SQLite
- поддерживает Telegram и VK с максимально похожей логикой

## Запуск

1. Создать виртуальное окружение
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Скопировать `.env.example` в `.env` и заполнить токены
4. Запустить:

```bash
python -m src.main
```

## Примечание

Если `VK_BOT_TOKEN` не задан, проект продолжит работать только с Telegram и фоновой логикой.

Если VK на локальном Windows упирается в SSL-сертификат сети/антивируса, можно временно включить:

```env
VK_DISABLE_SSL_VERIFY=true
```
