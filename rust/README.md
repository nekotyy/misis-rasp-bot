# Перенос на Rust

Каталог `rust/` содержит библиотеку переноса, которая пока не запускает ботов, API, админку или фоновые задачи и не заменяет Python-приложение. Перенесены модели расписания, нормализация дефисов, подгруппы, сравнение пар, календарные границы, разбор источников, подписи подписок, архив SQLite, разбор и загрузка расписания колледжа и университета, форматирование и сравнение изменений, операции пользователей и связанных аккаунтов, выбор получателей и основу синхронизации, транзакционное ядро очереди доставки, подготовка уведомлений и транспорт Telegram/VK, основы long poll и проверка хешей паролей админки.

Проверка: `cargo test --manifest-path rust/Cargo.toml`. Для SQLite требуется работающий C-компилятор.

Дальнейший перенос требует реализации и проверки совместимости хранения, обработки расписания, уведомлений, Telegram и VK, веб-сервисов, безопасности и развёртывания до переключения приложения на Rust.
