# Вклад в проект

Спасибо, что хотите помочь MISIS Schedule Bot!

## Как участвовать

- Откройте issue для багов или запросов фич.
- Для небольших правок можно сразу открыть pull request.
- Для крупных изменений сначала обсудите идею в issue.

## Настройка разработки

1. Скопируйте пример окружения:

```bash
cp .env.example .env
```

2. Установите зависимости:

```bash
uv sync --frozen
```

3. Запустите бота:

```bash
uv run --frozen -m src.main
```

4. Запустите веб-дашборд:

```bash
uv run --frozen uvicorn web_configurator.app:app --host 0.0.0.0 --port 8080
```

## Проверки

```bash
python -m compileall src web_configurator
python -m pip check
```

## Чек-лист для PR

- Опишите, что изменилось и почему.
- Держите изменения фокусированными и компактными.
- Обновите README или документацию, если поменялось поведение.
- Убедитесь, что проходят `compileall` и `pip check`.

## Стиль

- Сохраняйте форматирование и нейминг проекта.
- Предпочитайте ясную, явную логику вместо «умных» сокращений.
