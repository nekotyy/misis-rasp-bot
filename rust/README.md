# Перенос на Rust

Каталог `rust/` содержит библиотеку переноса, которая пока не запускает ботов, API, админку или фоновые задачи и не заменяет Python-приложение. Перенесены модели расписания, нормализация дефисов, подгруппы, сравнение пар, календарные границы, разбор источников, подписи подписок и отдельные операции архива SQLite.

Проверка: `cargo test --manifest-path rust/Cargo.toml`. Для SQLite требуется работающий C-компилятор.

Дальнейший перенос требует реализации и проверки совместимости хранения, обработки расписания, уведомлений, Telegram и VK, веб-сервисов, безопасности и развёртывания до переключения приложения на Rust.
