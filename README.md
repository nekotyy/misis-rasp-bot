# MISIS Schedule Bot

Один Python-проект для Telegram и VK-бота с общим парсером расписания, SQLite-базой, домашними заданиями, админкой и уведомлениями.

## Что умеет

- парсит расписание с сайта колледжа
- показывает расписание на сегодня, завтра и через 2 дня
- хранит пользователей, домашние задания, вложения и слепки расписания в SQLite
- рассылает уведомления об изменениях расписания
- рассылает уведомления о новом ДЗ
- поддерживает Telegram и VK
- умеет привязывать Telegram и VK аккаунты

## Локальный запуск

1. Скопировать `.env.example` в `.env`
2. Заполнить токены и ID администратора
3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Запустить:

```bash
python -m src.main
```

## Docker / VPS

Проект подготовлен для запуска через Docker Compose.

1. Скопировать проект на VPS
2. Скопировать `.env.example` в `.env`
3. Заполнить:

```env
TELEGRAM_BOT_TOKEN=
VK_BOT_TOKEN=
ADMIN_TELEGRAM_ID=
ADMIN_VK_ID=
VK_BOT_URL=
APP_TIMEZONE=Europe/Moscow
```

4. Запустить:

```bash
docker compose up -d --build
```

5. Посмотреть логи:

```bash
docker compose logs -f
```

6. Обновить после новых коммитов:

```bash
git pull
docker compose up -d --build
```

## Что сохраняется на VPS

После запуска Compose создается папка `runtime/`, в которой лежат:

- `bot.db`
- вложения ДЗ

Это значит, что после пересборки контейнера база и файлы не пропадут.

## Примечания

- если `VK_BOT_TOKEN` не задан, проект продолжит работать только с Telegram
- `VK_DISABLE_SSL_VERIFY=true` обычно нужен только для локального Windows, на VPS лучше оставить как есть или выключить
