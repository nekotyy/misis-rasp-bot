# Перенос на Rust

Каталог `rust/` содержит библиотеку переноса, которая пока не запускает ботов, API, админку или фоновые задачи и не заменяет Python-приложение. Перенесены модели расписания, нормализация дефисов, подгруппы, сравнение пар, календарные границы, разбор источников, подписи подписок, архив SQLite, разбор и загрузка расписания колледжа и университета, форматирование и сравнение изменений, операции пользователей и связанных аккаунтов, выбор получателей и основу синхронизации, транзакционное ядро очереди доставки, подготовка уведомлений и транспорт Telegram/VK, основы long poll, часть сценариев Telegram, каталоги и поиск расписания, а также проверка хешей паролей админки.

Проверка: `cargo test --manifest-path rust/Cargo.toml`. Для SQLite требуется работающий C-компилятор.

Дальнейший перенос требует реализации и проверки совместимости хранения, обработки расписания, уведомлений, Telegram и VK, веб-сервисов, безопасности и развёртывания до переключения приложения на Rust.

`schema.sql` отражает схему новой базы после миграции `20261105_0007` и инициализации Python. Rust-инициализация пока принимает только пустую базу либо существующую базу этой версии с необходимыми таблицами, полями и уникальными индексами; старые версии не обновляются автоматически.

Частично перенесённый обработчик Telegram сохраняет результат события и отметку обработки в одной транзакции, а позицию long poll сдвигает после записи в очередь. Неподдерживаемые события не подтверждаются. Для поддержанных запросов расписание берётся из кэша либо загружается с источника; выбранный вариант университетской недели проверяется по ответу сайта. Эти компоненты ещё не подключены к рабочему процессу приложения.

В переносимом поиске предусмотрены предпросмотр группы, преподавателя или аудитории, выбор при неоднозначном совпадении и повторное использование сохранённых снимков. Предпросмотр не меняет подписку пользователя.
Выбор университетской подгруппы проверяет доступные варианты и сохраняет настройку пользователя и связанной подписки в одной транзакции с ответом.
