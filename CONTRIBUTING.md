# Руководство по вкладу в проект (Contributing Guide)

Спасибо за проявленный интерес к развитию **MISIS Schedule Bot**! Этот документ поможет вам развернуть окружение, понять принятые стандарты и отправить пул-реквест.

---

## 🛠️ Настройка окружения для разработки

### 1. Клонирование и зависимости
Репозиторий использует менеджер пакетов `uv` (Python 3.12+):

```bash
git clone https://github.com/nekotyy/misis-rasp-bot.git
cd misis-rasp-bot

# Копирование переменных окружения
cp .env.example .env

# Установка зависимостей в виртуальное окружение
uv sync
```

### 2. Запуск компонентов локально

* **Telegram и VK Боты + Фоновые службы:**
  ```bash
  uv run python -m src.main
  ```

* **Веб-админка (FastAPI / Uvicorn):**
  ```bash
  uv run uvicorn web_configurator.app:app --host 127.0.0.1 --port 8080 --reload
  ```

## 🧪 Правила разработки и автотесты

В проекте действует **строгое правило по покрытию тестами**:

> ⚠️ При добавлении любой новой функции или изменении существующей бизнес-логики вы **обязаны написать соответствующий unit/smoke тест** в папке `tests/` и прогнать полный набор проверок перед коммитом.

### Запуск полного набора проверок:

```bash
# 1. Проверка синтаксиса компиляцией
uv run python -m compileall src web_configurator tests scripts

# 2. Запуск всех модульных и smoke тестов
uv run python -m unittest discover -s tests -p "test_*.py" -v
```

## 🌿 Правила работы с Git и коммитами

1. **Ветки**: Основная ветка разработки — `development`. Создавайте фича-ветки от `development`.
2. **Коммиты**:
   * Пишите commit message на русском языке.
   * Форматируйте в форме действия: *«добавил...»*, *«починил...»*, *«настроил...»*.
   * Сохраняйте коммиты атомарными (одна задача — один понятный коммит).
3. **Версионирование**: Если ваше изменение готовит новый GitHub Release, обновите версию в `pyproject.toml` (`version = "X.Y.Z"`) и выполните `uv lock`.

## 📋 Чек-лист перед отправкой Pull Request

- [ ] Код написан лаконично, без косметологического массового рефакторинга.
- [ ] Написаны Unit/Smoke тесты в папке `tests/` для всей новой логики.
- [ ] Все 40+ автоматических тестов успешно проходят (`OK`).
- [ ] Документация (`README.md` / `.env.example`) обновлена, если добавились новые переменные окружения.
- [ ] Веб-админка и боты проверены на отсутствие регрессий.
